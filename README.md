# WrightKit Homebrew Tap

Homebrew tap for [Wright](https://github.com/wrightkit/wright) — the
tooling-first semantic platform for the Overwatch Workshop and OverPy
ecosystem. Provides `wright` and `wright-lsp` as standalone macOS binaries
(Apple Silicon and Intel); nothing here builds Wright from source.

```sh
brew tap wrightkit/tap
brew install wrightkit/tap/wright
```

Upgrade after a new release with:

```sh
brew upgrade wrightkit/tap/wright
```

## How the formula is kept up to date

`wright.rb` is not edited by hand. Every
[wright release](https://github.com/wrightkit/wright/releases) carries the
authoritative formula generated by the release pipeline from the published
checksums (`wright-<version>.homebrew.rb` attachment). The `Sync formula`
workflow in this repository checks daily for a new release, downloads that
attachment, and commits the update, so a new version lands in the tap within a
day of its release. It can also be run manually from
Actions → Sync formula → Run workflow.

> Note: GitHub disables scheduled workflows in public repositories after 60
> days without activity. Each formula sync is a commit, so regular Wright
> releases keep this enabled. If it is ever disabled, re-enable it with
> `gh workflow enable sync-formula.yml --repo wrightkit/homebrew-tap` or in the
> Actions tab.
